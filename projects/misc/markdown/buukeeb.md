BuuKeeb is a custom mechanical keyboard PCB I made as both a way to learn PCB design, but also because I struggled to find something that fit my very specific niches.

The keyboard features:
- 105 keys with ISO enter for the 0.01% population of the world who types on a Portuguese layout. Media key support.
- [QMK](https://qmk.fm/) support thanks to the STM32F072 microcontroller
- Hotswappable MX switches
- N-Key Rollover
- Per Key LEDs on the north side, individually addressible. [OpenRGB](https://openrgb.org/) support.
- LED indicators for Caps Lock, Numlock, and Scroll Lock
- Completely open source

I wrote a ginormous blog post about the creation process, which also serves as a sort of tutorial for anyone looking to get into mechanical keyboard design.
